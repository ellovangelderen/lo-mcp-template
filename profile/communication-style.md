# Communication style

How you write and want things written — so every surface sounds like you.

Cover:
- Tone (direct? formal?), preferred length, language(s).
- Pet peeves (e.g. no em dashes, no filler, no corporate speak).
- How to disagree with you (bluntly? with options?).

Example line:
> Direct and short. Lead with the outcome. Never open with "Great question!".
